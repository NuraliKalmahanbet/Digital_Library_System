# Digital Library System 📚

![Java](https://img.shields.io/badge/Java-17%2B-orange.svg)
![OOP](https://img.shields.io/badge/Architecture-OOP-success.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

Консольная система управления цифровой библиотекой, разработанная на языке **Java**. Проект построен на принципах объектно-ориентированного программирования (ООП) и демонстрирует навыки проектирования чистой архитектуры, работы с коллекциями (Java Collections Framework) и обработки данных.

---

## 🔥 Ключевой функционал

### 📖 Управление каталогом книг
* **Учет фонда:** Добавление новых книг, удаление списанной литературы.
* **Гибкий поиск:** Поиск книг по названию, автору, жанру или уникальному идентификатору (ISBN/UUID).
* **Контроль статусов:** Отслеживание доступности книги в реальном времени (доступна/выдана).

### 👥 Управление пользователями
* **Ролевая модель:** Разграничение прав и возможностей для Администраторов/Библиотекарей и простых Читателей.
* **Профили читателей:** Хранение истории операций, списка активных книг на руках и персональных данных.

### 🔄 Процесс выдачи и возврата
* Автоматическая валидация доступности экземпляра перед выдачей.
* Фиксация дат выдачи, контроль сроков пользования литературой.

### 💾 Хранение данных (Data Persistence)
* Сохранение состояния системы между запусками приложения (использование файлового ввода-вывода Java I/O / NIO или сериализации).

---

## 🛠 Стек технологий

* **Язык программирования:** Java (Рекомендуется JDK 17 или выше)
* **Парадигма:** Объектно-ориентированное программирование (Инкапсуляция, Наследование, Полиморфизм, Абстракция) + SOLID принципы.
* **Инструменты:** Java Collections API (List, Map, Set), Java IO / NIO для работы с данными.

## 📐 Структура и архитектура проекта

Код проекта разбит на логические пакеты (packages) для разделения зон ответственности (Separation of Concerns):

```text
📁 Digital_Library_System/
│
└── 📁 src/
    ├── 📁 models/              # Сущности (POJO классы)
    │   ├── Book.java           # Модель книги
    │   ├── User.java           # Базовый класс пользователя
    │   ├── Reader.java         # Класс читателя
    │   └── Librarian.java      # Класс библиотекаря
    │
    ├── 📁 services/            # Управление бизнес-логикой
    │   └── LibraryService.java # Основной контроллер (выдача, поиск, возврат)
    │
    ├── 📁 utils/               # Вспомогательные модули (работа с файлами, валидация)
    │   └── DataManager.java    # Чтение/запись данных
    │
    └── Main.java               # Точка входа в приложение (метод main)
🚀 Инструкция по запуску
Требования
Установленный комплект разработки JDK 17 (или выше).

Настроенные переменные окружения (JAVA_HOME).

Запуск через терминал (CLI)
Клонируйте репозиторий:

Bash
   git clone [https://github.com/NuraliKalmahanbet/Digital_Library_System.git](https://github.com/NuraliKalmahanbet/Digital_Library_System.git)
Перейдите в корень проекта:

Bash
   cd Digital_Library_System
Скомпилируйте исходный код:

Bash
   javac -d bin src/Main.java src/models/*.java src/services/*.java src/utils/*.java
Запустите скомпилированное приложение:

Bash
   java -cp bin Main
Запуск в IDE
Вы также можете просто открыть папку проекта в любой современной среде разработки:

IntelliJ IDEA (Рекомендуется)

Eclipse

VS Code (с установленным Java Extension Pack)

Просто запустите класс Main.java, нажав зеленую кнопку Run.
